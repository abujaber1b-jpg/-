# ملف الدم — لعبة القضايا الجنائية والمحاججة (متوافق مع Render)

## المميزات الرئيسية
1. **لوحة تحكم المقدم**: تحديد عدد المجموعات (2 إلى 8)، إنشاء رموز دعوة وروابط مباشرة لكل مجموعة.
2. **30 قضية جنائية دموية ومشوقة**: تُخلط عشوائياً عند بدء كل لعبة جديدة مع ملخص لكل قضية عند المقدم.
3. **رسومات مسارح الجريمة**: لكل قضية مشهد جنائي بصري خاص بها.
4. **خصوصية الحل النموذجي والنقاط**: الحل النموذجي يظهر للمقدم فقط، والنقاط تبقى محجوبة عن المجموعات حتى نهاية المناقشة.
5. **تقييم آلي + تحكيم المقدم**: مقارنة آلية لإجابات المجموعة مع الحل النموذجي واقتراح الدرجات، مع إمكانية تعديل الدرجات وكتابة سبب كل نقطة من قِبل المقدم:
   - من هو الجاني: 10 درجات
   - السبب ولماذا صار الجاني: 30 درجة
   - اكتشاف التناقضات: 15 درجة
   - ملاحظة استثنائية: 5 درجات
   - الإلقاء: 20 درجة
   - المحاججة وكشف ثغرات الخصم: 20 درجة

## طريقة الرفع على موقع Render
1. ارفع مجلد المشروع إلى مستودع في **GitHub** (أو استخدم Blueprint عبر ملف `render.yaml`).
2. في موقع **Render** اختر **New -> Web Service** واربط المستودع.
3. تأكد من الإعدادات التالية:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn --workers 1 --threads 8 --bind 0.0.0.0:$PORT app:app`
4. اضغط **Deploy Web Service** وسيعمل الموقع مباشرة.
